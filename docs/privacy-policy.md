# NevusSafe Privacy Policy

**Effective date: 7 September 2026**

NevusSafe stores files locally on the user's device and encrypts file content
with AES-256-GCM before it is written to local or cloud storage. The NevusSafe
API receives file metadata needed for synchronization, but not plaintext file
content or encryption keys.

## Google Drive

When backup is enabled, NevusSafe uses Google OAuth 2.0 and requests only the
`https://www.googleapis.com/auth/drive.file` scope. This permits access to
files created or opened by NevusSafe, including the dedicated **NevusSafe
Cloud** folder. Access tokens are stored using the platform secure storage and
can be revoked from the Google Account security settings.

## Data and retention

Users control their local files and may delete cloud backups from the app or
Google Drive. Account and file metadata are retained only for operating
synchronization and are deleted according to the service's account deletion
process.

## Contact and changes

Publish a support contact and the production data-retention period before
submitting to an app store. This policy will be updated when data practices
change.
